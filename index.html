FlatConvert

FlatConvert is my most active and popular project. It is a file conversion tool that allows users to easily convert files between different formats. Whether you need to convert images, videos, or documents, FlatConvert is here to help.

Features:

  • Fast and efficient conversion
  • Intuitive user interface
  • Support for a wide range of file formats
  • Coming soon on GNOME Software and via Flatpak
